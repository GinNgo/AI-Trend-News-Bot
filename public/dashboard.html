Cách lấy API YouTube

  1. Vào Google Cloud Console tạo Project. Bật YouTube Data API v3.
  2. Tạo OAuth client ID (Web application). Redirect URIs: http://localhost:3050/oauth2callback.
  3. Tải file JSON về, đổi tên thành client_secret.json để vào thư mục dự án, sau đó bấm nút Đăng nhập OAuth2.

Cách lấy API TikTok

  1. Vào TikTok for Developers tạo App.
  2. Cấp quyền video.upload và video.publish. Copy Client Key và Secret dán vào ô trên.

* Nếu để trống, TikTok sẽ chạy ở chế độ Mô phỏng (Mock Sandbox).

Cách lấy API Facebook Reels

  1. Vào Meta for Developers tạo App Doanh nghiệp.
  2. Cấp quyền pages_manage_posts, pages_read_engagement, publish_video.
  3. Sinh Page Access Token dài hạn bằng Graph API Explorer và lấy Page ID dán vào ô trên.

* Nếu để trống, Facebook sẽ chạy ở chế độ Mô phỏng (Mock Sandbox).

Cách lấy API Instagram Reels

  1. Liên kết Instagram Professional Account với Facebook Page.
  2. Trên Meta Developers, cấp quyền instagram_content_publish, instagram_basic.
  3. Dùng endpoint /me/accounts?fields=instagram_business_account để lấy Account ID.

* Nếu để trống, Instagram sẽ chạy ở chế độ Mô phỏng (Mock Sandbox).
