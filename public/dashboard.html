Cách lấy API YouTube

  1. Vào Google Cloud Console tạo Project. Bật YouTube Data API v3.
  2. Tạo OAuth client ID (Web application). Redirect URIs: http://localhost:3050/oauth2callback.
  3. Tải file JSON về, đổi tên thành client_secret.json để vào thư mục dự án, sau đó bấm nút Đăng nhập OAuth2.

🚀 Hướng Dẫn Tự Động Hóa Đăng Video Lên TikTok Studio

Hệ thống sử dụng cơ chế Trình duyệt Tự động (Browser Automation) để đăng tải video trực tiếp vào TikTok Studio mà không cần xét duyệt API nhà phát triển phức tạp.

  1. Bấm nút 🔑 Mở Trình Duyệt Đăng Nhập TikTok ở trên. Hệ thống sẽ mở một cửa sổ trình duyệt Edge / Chrome độc lập.
  2. Trên cửa sổ vừa mở, đăng nhập vào tài khoản TikTok của bạn (qua QR code, mật khẩu hoặc Google). (Chỉ cần đăng nhập 1 lần duy nhất, cookies được lưu vĩnh viễn trong data/tiktok_profile).
  3. Sau khi đăng nhập xong, bấm công tắc BẬT ở góc trên thẻ TikTok và bấm 💾 Lưu.
  4. Bấm 🔌 Test để kiểm tra trạng thái đăng nhập hoặc 🚀 Test Đăng để thử nghiệm xuất bản một video mẫu.
  5. Từ nay, mỗi khi Bot render xong video, video sẽ tự động được tải lên, điền tiêu đề & hashtags theo kênh, và bấm nút Đăng hoàn toàn tự động!

💡 Mẹo: Bạn có thể giữ hoặc đóng cửa sổ trình duyệt đó bất kỳ lúc nào. Khi cần xuất bản, Bot sẽ tự động gọi lại phiên làm việc mà không bao giờ mất đăng nhập.

Cách lấy API Facebook Reels (Token Vĩnh Viễn Không Hết Hạn)

  1. Truy cập Meta Graph API Explorer ↗.
  2. Tại mục User or Page: Chọn đúng Fanpage của bạn (Ví dụ: AN NEWS 24/7). (Không chọn User Token để tránh bị hết hạn sau 24h).
  3. Cấp đủ 4 quyền: pages_manage_posts, pages_read_engagement, pages_show_list, publish_video.
  4. Bấm Generate Access Token → Copy token dán vào ô trên rồi bấm 💾 Lưu & 🔌 Test.

💡 Tính năng tự động: Ngay cả khi bạn lỡ dán User Token, hệ thống sẽ tự động quét danh sách Fanpage và trích xuất Page Token Vĩnh Viễn cho bạn!

Cách lấy API Instagram Reels

  1. Liên kết Instagram Professional Account với Facebook Page.
  2. Trên Meta Developers, cấp quyền instagram_content_publish, instagram_basic.
  3. Dùng endpoint /me/accounts?fields=instagram_business_account để lấy Account ID.

* Nếu để trống, Instagram sẽ chạy ở chế độ Mô phỏng (Mock Sandbox).
