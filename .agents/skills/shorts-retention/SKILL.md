# Shorts Retention Skill

## Purpose
Optimizes video structure to minimize Swipe-Away Rate (<25%) and maximize Average Percentage Viewed (>100%).

## Key Retention Mechanics
1. **Zero-Bumper Hook (0.0s - 1.5s)**:
   - Frame 0 must contain bold contrast, a category badge, and sound impact (whoosh/boom).
   - Never use channel intro logos or greetings ("Hi guys", "Welcome back").
2. **Pattern Interrupts (Every 2-3s)**:
   - Alternating color accents (Cyan, Gold, Emerald, Purple).
   - SFX punctuation (Pop, Ding, Swish) on key numerical reveals.
3. **The Endless Loop (Seamless Re-hooking)**:
   - Eliminate closing greetings ("Thanks for watching!").
   - End on a cliffhanger or open premise that flows naturally back into the opening sentence.
